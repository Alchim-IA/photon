Features

Everything you need to digitize

From scanning to AI-powered classification, Photon handles your entire document workflow.

Smart Scanning

Auto-crop, deskew, denoise, and whiten backgrounds automatically. Supports USB, network (eSCL), and batch scanning.

OCR Text Recognition

Extract text from any scanned document in 50+ languages. Search your documents by their content.

Encrypted Vault

Store sensitive documents in a password-protected vault with AES-256 encryption. Your data stays yours.

AI Classification

Automatically detect document types: invoices, IDs, contracts, prescriptions and more. Powered by Groq AI.

Advanced PDF Export

PDF/A compliance, password encryption, watermarks, digital signatures, and annotations baked right in.

Automation Rules

Create IF/THEN rules to auto-rename, auto-tag, and auto-file documents based on their content or type.

Table Detection

Automatically detect tables in scanned documents and export them as CSV for spreadsheet use.

Data Redaction

AI detects sensitive data (emails, phone numbers, IDs) and lets you redact them irreversibly before export.

Multi-page Documents

Combine multiple scans into a single PDF with drag-and-drop reordering. Perfect for multi-page contracts.

Interface

Designed to impress

Glassmorphism UI with light & dark themes, fluid animations, and pixel-perfect details.

Dark Mode

Frosted glass panels with accent glow effects

Light Mode

Clean, bright interface with subtle translucency

Tech Stack

Built with modern tools

Native performance with web flexibility. Rust for the backend, React for the UI.
